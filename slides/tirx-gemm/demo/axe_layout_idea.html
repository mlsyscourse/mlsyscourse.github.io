Axe Layout: Core Idea

Declare layout once → operate on logical tiles → compiler handles the rest

1
📐
Declare Buffer with Layout
Bind a physical layout to each buffer at allocation time. Layout encodes axes, swizzle, and memory mapping.
Asmem = pool.alloc(
  (128, 64), "fp16",
  layout=tma_shared_layout(...))
2
🧩
Operate on Tiles
Write high-level tile operations using logical coordinates. Slicing, copying, and MMA all work on tile views.
Tx.copy_async(Asmem, A[m:m+128, k:k+64])
Tx.gemm_async(tmem, Asmem, Bsmem)
3
⚡
Fast Access Guaranteed
Layout ensures bank-conflict-free SMEM access via swizzling, coalesced global loads, and correct TMEM lane mapping — all automatic.
4
🔧
Deduce Low-Level Instructions
Compiler reads the layout to generate correct PTX instructions — descriptor encoding, address offsets, swizzle modes.
SmemDescriptor: base | swizzle<<62
tcgen05.mma [...], a_desc, b_desc, idesc
Key insight: You never manually compute addresses or encode descriptors. Write Tx.gemm_async(tmem, Asmem, Bsmem) and the layout tells the compiler everything it needs to emit the right hardware instructions.
