You write TIRx (left) → compiler deduces PTX (right)

You write: TIRx (~8 lines)
# 1. Declare buffers with layout pool = Tx.PoolAllocator(buf.data) Asmem = pool.alloc((128,64), "fp16", layout=tma_shared_layout(...)) Bsmem = pool.alloc((128,64), "fp16", layout=tma_shared_layout(...)) T.ptx.tcgen05.alloc(tmem_addr, n_cols=512) # 2. Operate on tiles Tx.copy_async(Asmem, A[m:m+128, k:k+64], dispatch="tma") Tx.gemm_async(tmem[:,:BLK_N], Asmem, Bsmem, dispatch="tcgen05")
Compiler generates: PTX
// From layout → SmemDescriptor desc = base_addr | (swizzle_mode << 62) | (ldo >> 4) << 16 | ... // From layout → correct TMA instruction cp.async.bulk.tensor.2d .shared::cluster.global [smem], [tmap], {x,y} // From layout → correct MMA with descriptors tcgen05.mma.cta_group::1.kind::f16 [tmem], a_desc, b_desc, idesc, 1
Three Memory Spaces, Three Layouts
SMEM
tma_shared_layout("fp16", SWIZZLE_128B, (128, 64))
K-major with 128B swizzle. TMA-compatible, bank-conflict-free.
TMEM
TileLayout(([128, 512], [1@TLane, 1@TCol]))
128 lanes × N cols. Hardware-managed, not directly addressable.
Register
TileLayout(([128, BLK_N], [1@tid_in_wg, 1]))
Per-thread view via warpgroup tid. Used for TMEM→Reg readout.
Layout drives code generation: When you call Tx.copy_async(Asmem, A[...]), the compiler checks Asmem's layout to choose between TMA vs thread-copy, compute the tensormap fields, and select the right swizzle mode — all from the layout declaration.
