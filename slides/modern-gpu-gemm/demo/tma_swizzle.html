TMA with Swizzle Option

TMA applies swizzle during copy — data arrives pre-swizzled in shared memory

8×64 fp16 (swizzled)
Key insight: TMA has a swizzle_mode field in the tensor map descriptor.
When set to SWIZZLE_128B, the hardware applies sector_col = logical_col XOR row during the copy.
Result: data arrives in shared memory already conflict-free for 8×8 column reads.
No software swizzle needed — just configure TMA and read naturally.
