Shared Memory (tiled, 128B swizzle)

64×128 fp16 → 2 groups of 64×64
Problem: 64×128 fp16 = 64 rows × 256 bytes/row. SWIZZLE_128B atom = 8×128B = 8×64 fp16.
Inner tile width = 64 fp16 = only half of 128 columns. Need tiling: 2 groups of 64×64.

3D TMA solution: treat shared memory as [nGroups, rows, innerCols].
Box shape: (1, 8, 128B) per TMA instruction.
3D coordinate: (group_idx, row_offset, 0).
TMA handles tiling + swizzle in one shot — software just iterates (group, row).
